# End-to-end UX review — 26 Nov 2026

This review covered the whole journey in the guest build (5175) and in the sign-in-required build (5174, against the local Supabase).

The pages reviewed were landing, sign-in, terms, My Studio, the editor's four steps, publish, the share page, Vote, Ranking and the guest Look page. Each was checked at 1440×900 and at 375×812.

## Fixed in this pass (uncommitted)

| Area | Problem | Fix |
|---|---|---|
| Landing | The footer's "Start creating" link went to `/studio`, which forces sign-in, while the hero promises no sign-up | Every "Start creating" now uses one `CreateLink`: signed out goes to `/create`, signed in goes to `/studio?new=true` |
| Editor | Each step opened with its panels scrolled to wherever the last step left them | Panels scroll to the top when the step changes (`create.tsx`) |
| Editor | On Preview & Publish, the avatar card was squeezed to about 60px, then disappeared once the publish confirm opened | That step now uses a single scrolling column (`studio-chrome.ts` `singleScroll`) |
| Editor | The step header changed height between steps, so the stepper jumped | The action row no longer wraps at 1280px and wider (`StepActions.tsx`) |
| Editor | The garment credit was shown twice on the first step | Kept the one over the 3D stage |
| Editor | New text took the brush colour, so it vanished into ink of the same colour; the Text tool had no colour choice | Text has its own colour, chosen to contrast with the cloth by default, plus a row of swatches in the Text tool |
| Editor | Esc didn't deselect after placing text | Esc deselects anywhere on the Design step and blurs the text field |
| Editor | Shortcuts were hidden in a collapsed section at the bottom of the tool column; `?` did nothing | `?` and a keyboard button next to Undo/Redo open a shortcuts dialog; the Undo/Redo tooltips show their keys |
| Editor | Layer rows wrapped five text links over two or three lines | Each row is one line (name, visibility, lock, ⋯), with the other actions in the ⋯ menu (`LayerRowMenu.tsx`) |
| Publish | Untitled designs were published without a name prompt | The confirm step has a "Name your design" field |
| Publish | The copy said "version v2" on a first publish | Version numbers only appear when republishing newer edits |
| Publish | A greyed-out "Published" button looked like the main action | It is replaced by a success panel with the link, Copy link, View page and Unpublish |
| Publish | Publishing took about 12s with nothing but the button label to show for it | A progress bar and step text ("Rendering view 3 of 5…", "Uploading…") |
| My Studio | Design cards showed a placeholder icon instead of the design | Cards already on screen load their thumbnail straight away, with the flat preview as a fallback |
| My Studio | Profile settings and Delete account sat inside the designs dashboard; the empty state had no call to action | A separate Account section at the bottom; the empty state has a heading and a "Create your first T-shirt" button |
| Vote | The filter listed 14 garments even when no designs used them | It only lists garments that have published designs |
| Vote, Ranking | The pages opened with dense rule paragraphs | A one-line intro plus a "How votes count" disclosure with the same facts |
| Phone header | "Home" was pushed off-screen at 375px | Below 768px, Home, Look and the account links move into the "More" menu |
| Guest Look page | It rendered the house placeholder body without the strokes or text | `lookRenderDocument` restores the template's model and layout |
| Guest board | Every garment, tee included, was credited to Style3D CG | `garmentCreditLine()` takes the credit from each garment |

## Studio mode (same day)

The studio (`/create`) is now a workspace. It has no site header; a single studio bar takes its place:

- **The bar:** one row at lg, about 50px tall. Before, the site header plus the studio header took about 200px.
- **On a phone:** two short rows, about 100px. Before, they took about 340px, and the 3D view on the Colour step grew from 192px to 439px.
- **Its contents:** the way out (to My Studio, Sign in, or home), the design's name and save state, compact step dots, Undo/Redo and the step's buttons.
- **Moved out of the bar:** Pro tools moved into the tool panel, the design description to Preview & Publish, and the garment credit to the foot of the tool panel.

## Still open (recommended next)

Status as of 28 Nov is in the next section.

1. **First step is redundant from My Studio.** A design created from My Studio already has its garment locked, so step 1 is a dead step. Start it at Colour instead.
2. **Concept previews in the guest publish step.** Environment, Attachments, Model Shoot and Short Video do nothing. The default name "Cotton 01" ignores the chosen fabric, and the preset tags are unrelated to the design.
3. **Share page has no 3D view.** `/s/$slug` shows static images only; an interactive 3D viewer would match the product promise.
4. **Two button styles.** The editor and landing page use rounded gradient pills; the share and vote pages use square, outlined capitals.
5. **Phone 3D stage.** The tee is small and partly covered by the camera bar. The studio bar fixed most of the chrome height.
6. **Hints stay up after the action is done.** For example, "Pick a side" still shows after you've drawn on a side.
7. **Cut sliders read "0%"** while their thumbs sit at different positions.
8. **Mismatched colour lists.** The garment step's "Available colors" (6) differ from the Colour step's swatches (8).
9. **No way to zoom or pan the flat panels, and no export or download of an image.**
